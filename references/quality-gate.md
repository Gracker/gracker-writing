# Writing Quality Gate

## 六、质检体系

写完后执行四层质检,任何一层不通过都需要修复后再检查。

### L1 硬性规则(零容忍)

命中即不合格:

- **禁用词**:第三节词库(3.1)零命中;Android/性能/系统机制文章中的领域术语例外必须能说明对象、边界和证据。
- **事实正确**:版本、路径、工具名、类名、参数值不能乱。
- **代码规范**:代码块标语言;省略代码有明确注释;不贴代码截图。
- **数据规范**:数据有单位、条件、基线或解释。
- **格式**:按 3.4 和 `references/copy-editing.md` 检查中英文空格、硬换行、Markdown 层级、标点、称呼、可见术语大小写和机器可读内容边界。
- **中文校对**:没有常见错词、状态词误译和歧义数字表达。
- **比喻**:没有夸张比喻、没有多层套比喻。
- **高频词自检**:对 `真正|实际上|其实|根本|彻底|确实` 做全文计数,单一词命中 ≥ 5 次视为不合格(按 3.3.6 判断标准压到 2-3 次以内)。
- **结构性元叙述**:3.3.8 列出的那几类元声明零命中。
- **活人感硬伤**:按 `references/human-feel.md` 检查意义通胀、顺手补分析、同义词轮换、凑三项和加粗过度。命中后必须具体判断,不能只报「AI 味」。
- **Android 术语边界**:涉及 Android/Perfetto/系统机制时,按 `references/android-terminology.md` 区分术语和黑话;不得把 `渲染链路`、`输入链路`、`Binder 调用链` 等有具体系统对象的词机械替换。

### L2 可读性

- **开头**:三句内进入主题并交代读者收益。
- **节奏**:长短句交替;高密度部分有呼吸点;连续四句以上句式长度相近 = 节奏呆板。
- **结构**:段落之间有自然过渡;每个板块有一个明确核心观点;整体有清晰的推进线。
- **读者视角**:读完每段能回答"这一段在说什么";没有需要回头重读才能理解的逻辑跳跃;专业术语有足够上下文。
- **领域术语上下文**:Android 等系统术语第一次出现时有范围说明;读者能把术语对应到模块、线程、trace 轨道或源码路径。
- **扫读一致性**:同一标题下 4 个及以上并列项时,命名结构、句式和信息密度一致;列表项不要有的写定义、有的写宣传、有的写结论。

**通过标准**:开头必须通过;6 项中至少 5 项通过。

### L3 内容深度

- **论据支撑**:每个核心判断至少有经验/数据/代码/图/引用之一支撑。
- **知识输出质量**:技术解释从"为什么存在"开始再到"怎么工作";不是聊天式顺带出来,也不是教科书式硬塞。
- **独创性**:有"换了别人写不出这个角度"的内容;不是通篇"正确但无信息增量"的常识。
- **对立面与客观性**:涉及判断时考虑了反方观点;没有"只说好处不说代价"的片面性。
- **可执行性**(仅限教程/方法论类):每个建议落到"今天就能做"的具体动作;坦诚说明学习成本和常见失败点。
- **具体性**:核心段落里能看到具体对象、具体动作或具体证据。只有抽象判断、趋势判断、价值判断,没有复查点,视为不通过。

**通过标准**:论据支撑、知识输出质量和具体性必须通过;其余 3 项至少 2 项通过(不适用跳过)。

### L4 活人感终审

**核心问题**:读完这篇,是一个有经验的人在认真分享,还是 AI 在批量输出?

- **温度感**:情绪表达是体感的("我当时觉得不对劲")还是知识性的("我感到非常困惑")?
- **独特性**:有作者个人视角的痕迹(个人经历/独特判断/特有表达习惯)还是去掉署名后完全猜不出是谁写的?
- **姿态**:语气是"同行在分享经验"还是"导师在教学生"?有没有滑入说教/营销/汇报腔?
- **心流**:从头到尾读,有没有注意力断掉需要回头理逻辑的地方?
- **骨架感**:随机抽 3-5 段,试着把每句话"无损"翻回英文。如果大量句子顺顺当当就能翻过去,骨架就是英文的——整体是翻译腔,按 3.3.7-3.3.10 和精修 mode 的"翻译腔根治方法"处理。
- **具体边角**:随机抽 3 段,能不能看到真实工作流痕迹、失败分支、数据条件、读者反馈或作者取舍。太干净、太顺滑、没有边角,就是 AI 整理感。
- **格式克制**:标题、加粗、列表是不是在服务扫读;如果靠密集加粗和整齐三项制造重点,视为 AI 味。

**通过标准**:整体感觉"像是真人写的"。任何一项感觉"AI 味太重"就需要返工。

### 质检报告格式

```
---
## 🔍 四层质检报告

**L1 硬性规则** ✅/❌
- 禁用词:X 处命中(列表)
- 事实硬伤:X 处 / 无
- 格式:X 处不一致(含硬换行)
- 中文校对:X 处错词/误译/数字表达问题
- 高频词:`真正` X 次 / `实际上` X 次 / ...(任一 ≥ 5 = ❌)
- 结构性元叙述:X 处
- 活人感硬伤:意义通胀 X 处 / 顺手补分析 X 处 / 同义词轮换 X 处 / 凑三项 X 处 / 加粗过度 X 处
- Android 术语边界:通过 / X 处误判或缺少范围说明

**L2 可读性** ✅/❌
- 开头、节奏、结构、读者视角、领域术语上下文、扫读一致性:逐项 ✅/❌

**L3 内容深度** ✅/❌
- 论据支撑、知识输出、独创性、对立面、可执行性、具体性:逐项 ✅/❌/不适用

**L4 活人感** ✅/❌
- 温度感、独特性、姿态、心流、具体边角、格式克制:逐项 ✅/❌

**总评**:4 层全部通过 / L1/L2 需修复后重检 / 建议人工复审
**最需修复**:[1-3 个具体问题]
```

**约束**:
- 质检只输出报告,**不自动修改内容**。
- 问题必须具体到段落/位置,禁止空泛评价。
- L4 通过不了时,给出"哪个段落 AI 味重"的具体指引。
- 质检报告不计入正文落盘。
