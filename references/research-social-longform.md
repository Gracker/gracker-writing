# 调研社交长文（知乎高阅读体）

用于 DeepResearch / 调研结果发到知乎、公众号、Telegram 可转发的社交长文。不用于 Android 机制长文、教程、FAQ。

样本结构来自知乎「恋猫」答 GPT-6 Astra（[回答](https://www.zhihu.com/question/2079054472190469850/answer/2079118482206152021)）。**只借结构和思考顺序，不借口癖。** 不写「米有」「学坏了」「能上天了」；不学网络梗。

## 思考顺序

正常人看完一堆榜，会先抓住「哪一点对不上」，再甩数字，再问这数字站不站得住。不是先写发布要点、规格、官方评测、AA、安全、边界。

1. 开口：一个意外或一个对不上的点（一句话，带数字）。
2. 每一拍：人话判断 → 两个对照数字 → 配图或原文截图。
3. 中间至少有一个真问题：两套榜打架、harness 不一样、价和分对不上。
4. 收束：还没看明白的那一块，或一句有条件的判断。不要总结金句，不要把全文再复述一遍。

## 形式

- 判断句可以加粗，加粗只加这一拍的那一句，不要整段加粗。
- 列表必须接在一句人话后面，列表项是事实或动作，不是目录名词。
- 两行能说清的对照用列表；harness / 价档用小表。
- 能配图就配图。图放在判断和数字后面，不要先丢图再解释。
- 官方原话用引用块，随后用自己的话钉一句边界。
- 标题像判断，不像栏目名。不要「发布要点」「明天怎么选」。

## 节奏

- 一段只打一个点。打完就换段，不要在一段里堆完所有 bench。
- 短句落判断，数字跟在后面。
- 允许「有点意外」「这就对不上」「先记这个数」。
- 技术长文仍不用「我认为 / 我建议」。社交长文可以用观察痕迹（「有点意外」「暂时对不上」），不要写成情绪表演。

## 禁止

- 导演句：官网把画面/卖点/叙事……；把评测拆成……
- 空比较：跳得更大、升幅大（没有两个数字）
- 调研报告骨架：摘要 → 规格 → 官方榜 → AA → 安全 → 怎么选
- changelog 综述、一、二、三、口号收尾
- 不是 X 而是 Y
- 为了像样本去写口语杂质、错别字、卖萌

## 质检（写完必做）

出声读第一句和每一拍的判断句。朋友之间不会这么开口，整拍重写。

删掉所有栏目式小标题后，文章还能靠「意外 → 数字 → 问题」往下走。走不动，就是还在写报告。
