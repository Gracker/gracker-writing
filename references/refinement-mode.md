# 改稿范围与原文恢复

先依据用户请求决定改动尺度，而不是让“去 AI 味”自动触发全文重写。

## 不同任务的范围

| 任务 | 默认处理 |
| --- | --- |
| 只审阅、给建议 | 列具体问题与影响，必要时给局部改法；不直接改原文件 |
| 校对、只改错字 | 处理指定范围内的错误，保留风格和结构 |
| 精修、润色 | 修含混、重复、生硬和衔接；保留观点、体裁与主要叙述顺序 |
| 重写、改编 | 可以调整结构和表达，但新增内容仍需材料支持 |
| 恢复原稿声音 | 对照可信版本，找回丢失的表达功能与真实细节，保留成立的纠错 |

用户明确给了更窄或更宽的范围，以该范围为准。不为常规的可逆编辑反复询问是否开始。

## 普通精修

先读全文，辨认文章在做什么、作者在哪些地方表达了判断或情绪。再处理能指出的问题，必要时参考[局部表达诊断](less-ai-tone.md)与[基础校对](copy-editing.md)。

可以拆开难读的句子、理顺指代和衔接，不用逐字保留所有句法。没有理由则不动，不靠预设的修改数量交差。大幅删除段落、重排章节、改变论点或加入新材料不属于默认精修。

事实错误与风格问题分开。任务包含事实核查时，用来源修正；任务只要求语言修改时，不用个人猜测更换作者结论。发现会影响理解的疑点应单独指出，不把它默默润色成事实。

## 对照恢复

按[作者声音](author-voice.md)识别经历、判断、读者关系和语气。先弄清原稿、修订稿、技术补注的版本关系，再恢复。

- 只补回有依据的内容，不从别篇文章搬经历。
- 纠错改变结论时，尽量保留当时的尝试和观察，让读者看懂为什么后来修正。
- 恢复量由实际损失决定，不受句式白名单或几处修改的配额限制。
- 无原稿可对照时，只润色现稿并说明依据不足，不声称已还原作者原意。

## 翻译与多语言

对照含义、语气强度和叙述身份。可以换成目标语言自然的说法，但不默默删掉细节、把犹豫译成确定、把他人经历译成作者经历。

不以“更地道”为由替作者增加赞美、讽刺或戏剧冲突。用户只让润色单一语言时，不默认扩改其他语言或文件。

## 回读与交付

逐处看差异，再连着上下段读：是否误删转折、造成残句、改变时间关系，或让信息失去归属。结构、链接、引用、机器可读内容的校对按实际改动面进行。

已授权改稿就交修订稿；只审阅就交发现。说明重要改动与仍需确认的问题，不把编辑过程写进面向读者的正文。
